PR review conversation model

Can a persistent PR conversation keep investigations useful while each re-review stays independent, with durable cancellation and safe publication recovery? Click through the proposed state model below. This file runs an in-memory simulation, not Pi. Pi and both reviewers run with raw shell/file access on a disposable GitHub Actions VM, sharing its credentials and network reachability. Tailscale connects it to durable storage on the homeserver. VM disposal and reconstruction are proposed recovery steps, not a claim that Pi restores temporary files. Clean primaries and re-reviewers own fresh conversations. Completed clean reports and their import markers enter the idle canonical conversation together in a proposed Pi transaction.
